 Краткое описание проекта
REST API для управления каталогом фильмов. Проект позволяет добавлять и просматривать информацию о фильмах. Реализован с использованием современного асинхронного фреймворка FastAPI и базы данных SQLite
Основные возможности приложения приведины ниже
Добавление фильмов: Создание новых записей с валидацией данных
Просмотр каталога: Получение списка всех добавленных фильмов
Валидация данных: Строгая проверка входящих данных с помощью Pydantic (например, рейтинг не может быть больше 10, а год — раньше 1888)
Ограничения БД: На уровне базы данных настроены проверки (CheckConstraints) для предотвращения некорректного ввода
Документация: Автоматически генерируемая интерактивная документация (Swagger UI)
Технологический стек и его данные
Язык программирования: Python
